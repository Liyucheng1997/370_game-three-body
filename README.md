# 三体 · 虚拟现实游戏（Three.js 复刻）

纯程序化建模 + 实时合成音效，无任何外部美术/音频资源。

## 运行

```bash
npm install
npm start
```

浏览器打开 http://localhost:5173 。

## 章节

- **第一章 · 乱纪元**：跟随周文王，经历恒纪元 → 巨日 → 长夜飞星 → 恒纪元。
  `F` 下令脱水，`E` 拾取纤维卷搬进干仓，`X` 自身脱水（时间加速），`R` 下令浸泡复苏。
- **第二章 · 人列计算机**：秦始皇巨像、逻辑门演示（`1` `2` 换旗，`Q` 换门）、三千万大军组阵、
  显示阵列实时描绘三体轨道（`V` 鸟瞰），最终三日凌空。

通用：`WASD` 移动，`Shift` 奔跑，鼠标环顾，`空格` 跳过对白。

## 结构

- `src/models/anatomy.js` 雕刻头部、眼球、发际线头发、胡须、手指、褶皱袍服、广袖
- `src/models/qin.js` 秦始皇（冕旒十二串五彩玉珠、玄衣纁裳、十二章纹、太阿剑）
- `src/world/army.js` 人列计算机：GPU 状态纹理驱动的数十万士兵与远景着色器
- `src/scenes/plain.js` / `src/scenes/qin.js` 两章剧情与玩法

开发调试：访问 `http://localhost:5173/?debug` 会加载 `src/debug.js`（逐帧推进、跳转剧情）。
